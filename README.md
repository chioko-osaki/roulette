# 景品抽選ルーレット（大崎市地域おこし協力隊フェス用）

タブレット1台・2日間のイベントで使うことを前提にした、
シンプルな景品抽選アプリです。サーバーやデータベースは使わず、
すべての情報はそのタブレットのブラウザ（localStorage）に保存されます。

## フォルダ構成

```
index.html          抽選画面・結果画面（来場者・スタッフが操作する画面）
admin.html          管理画面（別ページ。スタッフのみが使用）
css/
  style.css          全体の基本デザイン
  roulette.css       ルーレットの見た目・アニメーション
  admin.css          管理画面のデザイン
js/
  storage.js         localStorageの読み書き（他のファイルはここを経由）
  inventory.js       景品・在庫・一時停止の管理（★景品の内容はここで編集）
  history.js         抽選履歴・抽選回数の管理
  roulette.js        ルーレットの表示・回転アニメーションのみ（抽選結果には無関係）
  sound.js           効果音（SE）管理（★SEはここで追加）
  admin.js           管理画面（admin.html）の表示・操作
  app.js             全体の初期化・画面遷移・抽選処理の司令塔
images/              景品画像を置く場所
audio/               効果音ファイルを置く場所（今は空）
```

## 事前準備（イベント前にやること）

### 1. 景品の内容を設定する

`js/inventory.js` の一番上にある `PRIZE_CONFIG` を編集してください。

```js
const PRIZE_CONFIG = [
  { id: 'A', name: 'A賞', image: 'images/prize-a.png', initialStock: 5 },
  { id: 'B', name: 'B賞', image: 'images/prize-b.png', initialStock: 10 },
  { id: 'C', name: 'C賞', image: 'images/prize-c.png', initialStock: 20 },
];
```

- `id`：景品ごとの記号（英字1文字などでOK。他の景品と重複しないように）
- `name`：来場者に表示される景品名
- `image`：`images` フォルダに入れた画像ファイルへのパス
- `initialStock`：イベント開始時点の在庫数

景品を追加・削除・変更した場合は、ページを再読み込みすると自動的に新しい内容で在庫が作り直されます（詳しくは `inventory.js` 内のコメントを参照）。

現在は `images/prize-a.png` などにサンプル画像（仮の丸いプレースホルダー）が入っています。実際の景品写真に差し替えてください。ファイル名を変えた場合は `PRIZE_CONFIG` の `image` の値も合わせて変更してください。

### 2. 動作確認（テストモード）

アプリを開くと、最初は自動的に「テストモード」になっています。
画面上部に「⚠️ テストモード」と表示されている状態で、何度か「抽選する」を押して動作を確認してください。

- テストモード中は、何回抽選しても在庫は減りません
- テストモード中の結果は抽選履歴にも残りません

### 3. 本番開始

画面右上の ⚙ から管理画面ページ（admin.html）を開き、「本番用にリセット」を押してください。
確認ダイアログが出るので、内容を確認してから実行してください。実行すると、

- すべての景品の在庫が初期値に戻る
- 抽選履歴・抽選回数がクリアされる
- 本番モードに切り替わる

この操作を行った後は、画面上部の警告バナーが消え、本番モードで運用できます。

## イベント当日の操作

- 来場者対応：来場者に「抽選する」ボタンを押してもらう → ルーレットが回る → 結果画面が表示される → 景品を渡す → スタッフが「次の方」を押す
- 来場者自身が「次の方」を押せないように、結果画面には「もう一度抽選する」ボタンはありません
- 在庫が足りているか、履歴を確認したいときは ⚙ から管理画面ページを開いてください
- 在庫を手動で増減したい、特定の景品を一時的に対象から外したい場合も管理画面ページから操作できます（管理画面から抽選画面に戻るには「抽選画面に戻る」リンクを使ってください）

## 効果音（SE）を追加したいとき

1. `audio` フォルダに音声ファイル（mp3など）を追加する
2. `js/sound.js` を開き、該当する行の `null` をファイルパスに書き換える

```js
const SOUND_FILES = {
  'draw-start': 'audio/draw-start.mp3',
  'roulette': 'audio/roulette.mp3',
  'win': 'audio/win.mp3',
};
```

これだけで反映されます。他のファイルを変更する必要はありません。

## ルーレットの演出を調整したいとき

`js/roulette.js` の `EXTRA_SPINS`（回転回数）や、`css/roulette.css` の `#wheel-rotor` の `transition`（回転時間・イージング）を変更してください。抽選結果を決めるロジックとは分離されているため、見た目だけを自由に調整できます。

## GitHub Pagesでの公開方法（概要）

1. このフォルダの中身をそのままGitHubリポジトリにアップロードする
2. リポジトリの Settings → Pages で公開設定を行う
3. 発行されたURLをタブレットのブラウザで開く

## トラブル時の考え方

このアプリは「2日間・スタッフが常駐するイベント」での利用を想定しているため、
細かいエラーはすべてコードで自動対応するのではなく、一部は現場のスタッフ対応を前提にしています。

| 状況 | 対応 |
|---|---|
| 景品画像が表示されない | コードで自動的に景品名だけの表示に切り替わります |
| すべての景品がなくなった | 「すべての景品が終了しました」と表示され、抽選ボタンが隠れます |
| 誤ってテストモードのまま抽選しそうになった | 画面上部に警告バナーが常時表示されます |
| 誤って「本番用にリセット」を押しそうになった | 確認ダイアログが表示されるため、そこで止められます |
| 端末の調子がおかしい／表示が崩れた | ページを再読み込みしてください（在庫・履歴は消えません） |
| 景品在庫の数が現場の実物と合わない | 管理画面の＋1／−1ボタンで手動修正してください |

## 更新履歴

- 管理画面を、index.html内のオーバーレイ表示から独立した`admin.html`に変更しました。あわせて、`hidden`属性がCSSの詳細度によって無効化される場合があった問題（見た目上「閉じるボタンが効かない」ように見える不具合）を修正するため、`css/style.css`に`[hidden] { display: none !important; }`を追加しています。

なお、ブラウザのサイトデータを手動で削除した場合など、localStorage自体が消えるケースまでは想定していません（今回の用途では過剰な対策と考え、実装していません）。
